MZÉÉMZIMÀ MUSIC - SPOTIFY-STYLE STARTER

This is a lightweight PWA starter, not a copy of Spotify and not a catalog of copyrighted music.

To turn it into an Android app:
1. Put these files on an HTTPS web host so index.html is publicly reachable.
2. Open the public URL in PWABuilder.
3. Choose Build My PWA -> Android -> generate the Android package.
4. Install the generated test package on the Samsung A12.

The app currently supports local/authorized audio, search, favorites, recently played,
play/pause, previous/next, shuffle and repeat.

For a true online catalog, connect a backend/catalog containing audio you own or are
licensed to stream. A 32 kbps stream is approximately 14.4 MB/hour before network overhead;
actual usage depends on the audio source and delivery.
